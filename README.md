# 📊 Macro-Quant Analyzer

경제·금융 분석 블로그 **[혜안]**의 정량적 매크로 진단 및 자산 배분 전략을 검증하기 위한 오픈소스 퀀트 분석 리포지토리입니다.

## 🚀 Key Objectives (핵심 분석 목표)
1. **매크로 충격의 증시 전달 메커니즘**: 실질금리(Real Yield)와 달러 인덱스(DXY) 동반 강세의 정량적 평가
2. **중앙은행 수급 검정**: 공공 부문 금 매수 모멘텀 이탈 및 둔화 가설 검증
3. **개인 투자자 수급 동향**: 금 선물 및 레버리지 ETF 순매수 과열 및 물타기 패턴 진단
4. **추적오차 및 괴리율 리스크**: 유동성 공백과 테일 리스크(Tail Risk) 측정
5. **퀀트 자산 배분 모델**: 베타 혜지 계수 및 기술적 지표(RSI < 30) 연동 동적 방어전략 백테스트
